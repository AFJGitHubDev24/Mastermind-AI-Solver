# Mastermind AI Solver using Z3 & Predicate Calculus

An autonomous AI code-breaker for the classic logic board game **Mastermind**, implemented as a single runnable Google Colab notebook (`Mastermind.ipynb`). The project uses First-Order Logic (Predicate Calculus) and Microsoft Research's **Z3 Theorem Prover** to deduce secret codes through cardinality constraints.

## 🎯 The Mastermind Game

Mastermind is a two-player game of deduction:

1. **The Secret Code:** The Codemaker hides a sequence of 4 colored pegs chosen from 6 available colors.
2. **The Guess:** The Codebreaker submits a candidate sequence of 4 colors.
3. **The Feedback:** The Codemaker scores the guess using indicator pegs:
* **Black Peg ($B$):** Correct color in the correct position (Exact Match).
* **White Peg ($W$):** Correct color, but in the wrong position (Partial Match).


4. **Goal:** The Codebreaker must crack the secret code in as few turns as possible.

---

## 🔬 Theoretical Foundation: Predicate Calculus to SMT

Rather than brute-forcing all $6^4 = 1,296$ possible combinations, the solver converts feedback from each turn into formal first-order logic predicates and cardinality constraints.

### 1. Variables & Bounded Domain

Let $S = [s_0, s_1, s_2, s_3]$ be the vector of integer variables representing the hidden secret code, where $s_i \in \{1, 2, 3, 4, 5, 6\}$.

### 2. Exact Match Constraint (Black Pegs)

For a guess vector $G = [g_0, g_1, g_2, g_3]$, the number of exact positional matches equals $B$:

$$\sum_{i=0}^{3} \mathbb{I}(s_i = g_i) = B$$

Where $\mathbb{I}$ is an indicator function returning $1$ if true and $0$ if false.

### 3. Total Color Overlap Constraint (Black + White Pegs)

To handle white pegs without double-counting positions, the notebook evaluates the minimum count of each unique color present in both the guess and secret:

$$\sum_{c \in \text{Unique}(G)} \min\left( \sum_{i=0}^{3} \mathbb{I}(s_i = c), \text{Count}(G, c) \right) = B + W$$

## 💻 Notebook Architecture (`Mastermind.ipynb`)

The notebook is structured into clear logical sections:

1. **Setup & Dependency Installation:** Installs `z3-solver` directly in the Colab environment.
2. **Feedback Engine:** Functions to score guesses and return Black and White peg counts.
3. **Z3 Constraint Formulator:** Translates feedback scores into Z3 predicate expressions (`If`, `Sum`).
4. **Interactive AI Game Loop:** Continuously queries Z3 for satisfiable models (`sat`), logs turns, updates constraints, and outputs the final solution.
